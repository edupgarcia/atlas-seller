# Atlas Seller

**Inteligência para suas vendas, em um só lugar.**

O **Atlas Seller** é uma plataforma de inteligência e gestão para sellers de marketplaces.

A proposta é centralizar dados de diferentes marketplaces e transformar informações de vendas, custos, taxas, anúncios e resultados em indicadores que ajudem o seller a entender melhor sua operação e tomar decisões mais informadas.

## 🚀 Visão do produto

O Atlas Seller está sendo desenvolvido para conectar diferentes canais de venda em uma única plataforma, permitindo ao seller acompanhar sua operação de forma consolidada.

Entre os principais objetivos estão:

- 📊 Consolidar vendas de diferentes marketplaces
- 💰 Calcular custos, taxas, comissões e resultados
- 📦 Acompanhar produtos, SKUs e custos
- 📈 Analisar faturamento, margem e lucro
- 📢 Considerar investimentos em publicidade
- 🔄 Sincronizar dados automaticamente com os marketplaces
- 🧠 Transformar dados operacionais em informações úteis para tomada de decisão

## 🔌 Integrações

### Amazon

Integração com a Amazon Seller Central utilizando a **Amazon Selling Partner API (SP-API)**.

A integração permite trabalhar com dados da operação do seller, incluindo pedidos, produtos e informações financeiras.

### Mercado Livre

A integração com o Mercado Livre está em desenvolvimento.

- Aplicação do Atlas Seller criada na plataforma do Mercado Livre
- Aplicação aprovada pelo Mercado Livre
- Interface de conexão com o Mercado Livre já disponível no Atlas
- Desenvolvimento da integração via API em andamento

### Temu

A integração com a Temu está em processo de implantação.

- Interface de conexão com a Temu já disponível no Atlas
- Aplicação submetida para aprovação
- Integração via API será desenvolvida após a liberação necessária da plataforma
